# Vibe Coding Feature Checklist

Use this checklist for every future feature. Copy it into the feature's task or verification notes and keep it current.

## Before implementation

- [ ] Spec exists
- [ ] Requirements are clear
- [ ] Goal, scenarios, acceptance criteria, and edge cases are documented
- [ ] Technical approach is decided
- [ ] Demo-critical scope and non-goals are explicit

## During implementation

- [ ] Follow existing architecture
- [ ] Keep changes focused
- [ ] Build the smallest coherent MVP first
- [ ] Avoid unnecessary dependencies and unrelated refactors
- [ ] Synchronize the Spec when a decision changes

## After implementation

- [ ] Test completed
- [ ] Failure and recovery paths verified
- [ ] Documentation updated
- [ ] Spec synchronized
- [ ] Demo path rehearsed
- [ ] OpenSpec verification completed with no critical issues
