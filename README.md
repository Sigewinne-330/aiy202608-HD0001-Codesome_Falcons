## AIY 黑客松选题

### 1. Deadline 日历

#### 核心功能：
1. **Agent 整合 Deadline 信息添加到日历（待办事项）当中**：
   * 不需要手动输入事件、紧急程度、分类归档。
   * 可以直接通过通知截图生成。
   * *改进办法*：使用微信的插件定时读取聊天记录，或者实时读取屏幕数据。
   * *日期模糊的问题*：可以让 Agent 追问解决。
2. **Schedule 灵活规避功能**：当出现日程冲突时，自动将可以提前的任务提前设置个人 deadline；长程任务自动分布到每一天，尽量保持均匀，防止某一天的任务过多。
3. **大型任务拆解**：指将“写论文”这种大型任务拆解成多个子任务，并分别自动设置 deadline。
4. **催 Deadline**：给 Agent 定义一个有趣的设定，然后风趣地提醒用户准时完成任务。
5. **（可能有用）改善拖延/内耗**：做一个与心理学有关的功能，用于改善用户的拖延症或者内耗。
6. **（重要！！！）安全围栏**（不一定能做到）。
7. **集成任务发布和整合的功能**。

### 2. Personal Knowledge Loop：个人知识闭环助手

#### 用户平时随手输入：
* 课堂笔记
* 语音想法
* 截图
* 网页内容
* 错题
* 老师反馈

#### AI 自动完成：
**收集 → 分类 → 关联旧知识 → 生成复习材料 → 定期回顾**

* **典型场景举例**：
  例如用户记录一道物理错题后，AI 判断错误属于“公式选择错误”，并在一周后推送一组相同错误类型的题，而不是简单地提醒用户重新看原题。

* **每周生成汇总报告（示例）**：
  > “你本周记录了 17 条内容，其中 5 条与动量有关。你在‘方向判断’和‘符号约定’上重复出错 3 次。”

* **亮点**：能体现长期记忆和个性化，但实现复杂度略高。
