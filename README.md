## ✨ 它能做什么

### 🤖 AI 对话规划助手（IBuddy Agent）

- **多模态输入识别**：支持文字和图片拖拽/粘贴/截图上传，AI 自动从聊天记录、通知截图、课件中提取任务名称和截止日期；遇到模糊日期会主动追问确认
- **流式对话 + 工具调用**：基于 SSE 的实时流式回复，Agent 可自主调用 16 个工具（任务 CRUD、子任务管理、日程分析、知识库检索等），完成从"聊天"到"写入数据库"的闭环操作
- **小任务 vs 完整规划自动判定**：Agent 智能区分"设个提醒就行"的单步任务和"帮我拆解"的复杂任务，按需启动不同流程
- **IB 学科知识库**：内置 Chemistry IA、Economics IA、Physics IA、Extended Essay、TOK 五大学科规划指南，Agent 在用户提及相关任务时自动检索，给出符合 IBO 官方标准的专业步骤拆解

### 📋 双模式任务管理

- **Todo 模式**：轻量待办，一键勾选完成，适合日常小任务
- **Process 模式**：长程流程任务，支持时间线容器 + 多里程碑子任务，每个子任务独立设置截止日期和优先级
- **手动创建 & AI 自动生成**：既可以手动添加任务和里程碑，也可以通过对话或专门的 AI 规划页面一键生成完整的分阶段计划

### 📅 日历全局视图

- **月视图日历**：所有任务、子任务、独立 deadline 以颜色编码色块清晰呈现在月历网格中（蓝色=todo、绿色系=process 时间线、橙色=deadline、三角标记=子任务），紧急/逾期项红色高亮
- **个人 Deadline 独立管理**：支持为任务设置"个人提前 deadline"（虚线边框区别于官方 DDL），可按需创建不关联任务的独立截止日
- **碰撞检测**：输入日期即可检测是否超过安全负载阈值（≥3 项触发警告）

### 🧠 AI 任务拆解与排期

- **逆向任务拆解**：输入如"写 3000 字论文，下周日前交"，AI 从 DDL 倒推生成 4-6 个阶段性子任务，分布到合理日期
- **分阶段时间线规划**：在规划页面输入任务描述和截止日期，AI 生成多阶段执行计划，包含预估工时、阶段名称和里程碑时间节点
- **进度追踪仪表盘**：首页展示任务总数、待处理数、逾期数和完成率；进度页面按 IA/EE/TOK/CAS 四大 IB 类别分类追踪，含风险标记

### 🔔 智能提醒引擎

- **多节奏提醒（cadence）**：默认在 D-2、D-1、D0、D+1、D+3、D+7 六个时间节点自动触发提醒，可追加自定义偏移量（最长 D+365）
- **LLM 生成个性文案**：AI 根据用户选择的角色卡（友好学长 / 技术极客 / 甜美学妹）生成带有人设风格的提醒标题和开场白，失败自动降级为确定性模板
- **双通道投递**：提醒同时推送到站内聊天消息和邮箱（SMTP），每条投递有完整的状态追踪和自动重试（最多 3 次）
- **独立 Worker 进程**：提醒系统以独立进程运行（APScheduler），与 HTTP 服务解耦，支持单次扫描（`--once`）和常驻模式
- **提醒历史**：可翻页查看历史 digest 记录，展开查看每条投递在各通道的送达状态

### 🎯 日程负载均衡（Scheduling Balancer）

- **预检拦截**：创建带日期的任务/子任务时，若单日负载超过阈值（4 项），系统自动弹出干预提示，展示当前负载和建议方案
- **多策略排期**：支持 balanced（均衡）/ conservative（保守）/ sprint（冲刺）三种排期策略
- **计划预览 & 一键应用**：生成排期计划后先以预览形式展示各项日期的变更对照，确认后原子化应用，支持撤销（undo）和重新排期（replan）
- **自动调度**：可在设置中开启自动调度，任务变更后自动检测日程负载并生成优化计划

### 💰 积分计费系统

- **积分经济**：1 积分 = 1000 tokens，新用户注册赠送 10,000 积分
- **用量看板**：显示余额概览、7 日消费趋势图、预计剩余天数
- **充值套餐**：四档积分套餐（6/30/68/128 元），含模拟支付流程
- **完整账本**：`token_ledger` 记录每一笔消费和充值，支持按时间翻页查询

### 🌐 其他亮点

- **三语国际化**：简体中文 / 繁體中文 / English，根据浏览器语言自动切换，Vuetify 组件同步翻译
- **邮箱验证注册**：安全的分步注册流程——请求验证码→邮箱收码→验证→注册，验证码加盐哈希存储，多层限流保护
- **响应式设计**：桌面端全功能布局（左侧任务抽屉 + 右侧 AI Agent 浮动面板 + 中心内容区），移动端自适应

## 🛠 用到的技术 / AI 工具

### AI / 大模型
- **Doubao（豆包 Seed 2.1 Pro）**：主力对话与多模态模型，通过 Ark API（火山引擎）调用，支持流式输出、工具调用（Function Calling）和视觉识别
- **DeepSeek Chat**：备用模型，豆包不可用时自动降级切换

### 后端
- **FastAPI** + **Uvicorn**：Python 异步 Web 框架，提供 RESTful API 和 SSE 流式端点
- **SQLAlchemy 2.0** + **MySQL 8.0**：ORM 与关系数据库，20 张业务表涵盖用户、任务、子任务、deadline、对话、提醒引擎、调度引擎、积分账本
- **APScheduler**：独立 Worker 进程的定时任务调度，驱动提醒扫描和每日日程分析
- **python-jose + bcrypt**：JWT 认证 + 密码哈希
- **Docker + docker-compose**：三容器部署（MySQL + Backend + Nginx 前端）

### 前端
- **Vue 3** + **Vite 6**：组合式 API + 极速热更新
- **Vuetify 3**：Material Design 3 组件库，提供响应式布局和主题系统
- **vue-i18n**：三语国际化
- **markdown-it + KaTeX**：Markdown 富文本渲染 + LaTeX 数学公式渲染
- **SSE（Server-Sent Events）**：流式 AI 对话实时推送到前端

### 部署
- **Nginx**：反向代理 `/api` 到后端，静态资源缓存，SPA fallback
- **Docker Compose**：一键启动全部服务
- 已部署至云服务器：http://ibuddy.cc

## 🚀 怎么跑起来

### 前提条件
- Python ≥ 3.10、Node.js ≥ 18、MySQL ≥ 8.0、Git

### 1. 克隆并配置

```bash
git clone <repo-url>
cd ib-deadline-assistant
cp backend/.env.example backend/.env
# 编辑 backend/.env，填写 DB_PASSWORD、ARK_API_KEY、SMTP 等
```

### 2. 初始化数据库

```bash
mysql -u root -p < backend/init_db.sql
```

### 3. 启动后端

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 4. 启动前端

```bash
cd frontend
npm install
npm run dev
```

### 5. 启动提醒 Worker（可选，用于催更功能）

```bash
cd backend
.venv/bin/python reminder_worker.py
```

浏览器打开 `http://localhost:5173` 即可使用。

### Docker 一键部署

```bash
docker compose up -d
```
