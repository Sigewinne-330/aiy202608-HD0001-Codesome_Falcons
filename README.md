## AIY 黑客松选题

### 1. Deadline 日历

#### 核心功能：
1. **Agent 整合 Deadline 信息添加到日历（待办事项）当中**：
   * 不需要手动输入事件、紧急程度、分类归档。
   * 可以直接通过通知截图生成。
   * *改进办法*：使用微信的插件定时读取聊天记录，或者实时读取屏幕数据。
   * *日期模糊的问题*：可以让 Agent 追问解决。
2. **Schedule 灵活规避功能**：当出现日程冲突时，自动将可以提前的任务提前设置个人 deadline；长程任务自动分布到每一天，尽量保持均匀，防止某一天的任务过多。
3. **大型任务拆解**：指将“写论文”这种大型任务拆解成多个子任务，并分别自动设置 deadline。
4. **催 Deadline**：给 Agent 定义一个有趣的设定，然后风趣地提醒用户准时完成任务。
5. **（可能有用）改善拖延/内耗**：做一个与心理学有关的功能，用于改善用户的拖延症或者内耗。
6. **（重要！！！）安全围栏**（不一定能做到）。
7. **集成任务发布和整合的功能**。

# 产品企划书：Workbuddy 校园生存指南 

### 核心功能模块划分 (Core Features)

#### 一、 全模态 DDL 捕获网：从自动化导入到碎片信息收敛
**无论是零散的微信通知，还是官方系统的海量作业，Agent 都能自动为你“收纳”。**

*   **1. 基础多模态录入 (通用)**：
    *   用户可以直接将聊天记录截图、PDF 课件首页截图，或者一段随口的语音（“下周五有个心理学 presentation”）发给微信里的 Agent。
    *   Agent 自动提取时间、地点、任务详情并生成日历事件。遇到“下周某天交”这种模糊指令，Agent 会主动追问确认，消除模糊感。
    *   小程序端提供美观的日历视图（日/周/月），允许用户手动添加常规日程（如上课、社团开会），作为 Agent 规划全局日程的基础底座。
*   **2. ManageBac 自动嗅探插件 (IB/国际生进阶)**：
    *   开发专属浏览器插件，静默嗅探并一键同步 ManageBac、Canvas 等校园管理系统上的官方 Calendar、作业 Dropbox DDL。
    *   实现“无需手动输入，DDL 自动上历”，彻底解放学生在多个平台间来回查对的时间。

#### 二、 双核长程任务拆解引擎：基础逻辑 + RAG 专家知识库
**面对需要几周甚至几个月的大型任务，AI 不仅帮你做，还教你怎么做。**

*   **1. 泛用型逆向任务拆解 (通用)**：
    *   针对诸如“写一篇 3000 字论文”的大型任务，Agent 根据交稿 DDL 进行“逆向排期”。
    *   自动拆解为“查阅资料”、“撰写大纲”、“初稿专注时刻”、“润色与防翻车缓冲期”，并为每一个子任务设定独立的微型 DDL。
*   **2. 学科级专家导师系统 (IB专属 - RAG 技术赋能)**：
    *   通过预先喂入大模型 IBO 官方指南（Guide）、评分标准（Rubrics）和高分范文分析，构建本地知识库。
    *   当用户输入“我要开始写历史 EE (拓展论文)”或“物理 IA”时，Agent 将调用知识库，给出**超越用户认知的专家级拆解**。例如拆解历史 EE，不仅是“查资料”，而是精确到“Week 1: 确定 RQ 与导师 Meeting”、“Week 3: 完成 OPCVL 来源分析”、“Week 10: 填写 RPPF 反思表”。
*   **3. 碎片化 CAS (课外活动) 追踪器**：
    *   Agent 定期主动发起话题：“这周参加辩论赛了吧？给你 3 分钟，马上对着我发条语音吐槽一下，我帮你自动丢进日程本里。” 极大降低长期任务的记录门槛，了解用户的cas安排，并且定时提醒用户完成cas任务和上传证据。

#### 三、 动态精力池管理：全局日程规避与负载均衡
**Agent 具备读取和修改日历的 Skill（技能），确保你每天的任务量都在人类可承受范围内。**

*   **1. 智能排雷与冲突规避 (通用)**：
    *   Agent 具备全局视野（读取日程）。当拆解子任务时，会自动避开用户已有的满课日、社团活动日，优先将高强度脑力任务安排在大块空闲时间。
    *   遇到临时新增的紧急任务导致“撞车”，Agent 会自动重新排期，将非紧急任务延后，优先保证核心 DDL。
*   **2. 极限状态负载均衡 (应对“地狱月”)**：
    *   针对 IB DP2 或期末季“多科 IA、模拟考与论文终稿”同时挤在同一周的地狱级现象，Agent 会启动“前置化解”。
    *   强行将部分任务的个人 DDL 提前 1-2 周，并把 1000 字的任务打碎成连续 5 天每天写 200 字，强行拉平用户的“每日精力消耗曲线”，防止考前崩溃。

#### 四、 有温度的 CBT 督导员：反内耗与情绪干预
**不再是冷冰冰的“系统提醒”，而是一个兼具幽默感和心理学技巧的鲜活搭子。**

*   **1. 戏精/幽默催收机制 (日常互动)**：
    *   通过 Persona 设定（如：经历过摧残但极其护短的学长/学姐），风趣幽默地催促 DDL。“报告主子，您的《社会学调研》距离 DDL 还有 48 小时，它现在看起来比您的发际线还要危险，请问是否现在开始抢救？”
*   **2. CBT (认知行为疗法) 危机干预 (反拖延)(待考虑)**：
    *   当用户主动向 Agent 抱怨“我太焦虑了，根本不想点开文档”，或者检测到子任务严重超期时，启动 CBT 疗法。
    *   利用“认知解离”和“微步骤启动”：“深呼吸，你现在不需要写出一篇满分作文。你只要花 3 分钟建一个空白 Word 档，把标题写上，然后你就去玩手机，好吗？”以此打破用户的启动阻力。

### 💡 方案优势总结

这套方案完美地呈现了**“金字塔结构”**的产品力：
*   **底层**：解决了输入和展示的问题（多模态识别、小程序日历视图）。
*   **中层**：解决了时间管理规划和算法调度的问题（通用任务拆解、日程防撞车排期）。
*   **顶层**：针对特定高净值/高痛点人群（IB生）提供了专业级的知识增强（RAG EE/IA 拆解），并提供了最高级的情绪价值（CBT与幽默互动）。
